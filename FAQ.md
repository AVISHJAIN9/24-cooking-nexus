# Frequently Asked Questions: Cooking Nexus Meal Planning API

### 1. What is Cooking Nexus Meal Planning API?
Nutritional optimization and culinary meal planning backend API with recipe graph queries.

### 2. What technology stack does it use?
Built with Node.js (Express), React / TypeScript.

### 3. Where is this project deployed?
Hosted live at: https://aj-cooking-nexus.onrender.com/health

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
