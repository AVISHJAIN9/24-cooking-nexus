## 4. Real-Time Transport Protocols Comparison

| Protocol | Latency | Bandwidth Efficiency | Server Connection State | Scalability | Fit for Cooking Nexus |
|---|---|---|---|---|---|
| **HLS / DASH (Chosen for Video)**| 2 - 6 seconds | Extreme (Byte-range caching) | Stateless HTTP | Unlimited via Edge CDN | Optimal for 60-second culinary reels |
| **Server-Sent Events (SSE)**| <250ms | High (No polling overhead) | Light state (HTTP stream) | High (Standard load balancers) | Optimal for AI Chat streaming |
| **WebSockets** | <50ms | High | Heavy state (Persistent TCP) | Complex (Requires Redis pub/sub) | Optimal for live masterclass chat |
| **WebRTC** | <200ms | High (Peer-to-peer / SFU) | Complex signaling | Challenging at 10k+ viewers | Optimal for 1-on-1 cooking coaching |
| **Short Polling** | 1 - 5 seconds | Terrible (90% empty replies) | Stateless | Poor | Anti-pattern; avoid |

## 5. Live Stream Chat Architecture (Redis Pub/Sub)
For the interactive live stream view (`LiveStreamPage.tsx`):
- Multiple Node.js backend nodes run WebSocket servers (Socket.io).
- Backend instances connect via a **Redis Pub/Sub Adapter**: when a viewer posts a comment on Server A, the message publishes to Redis channel `livestream:chef_marco`, broadcasting to all connected viewers across Servers B and C within 30 milliseconds.

---

## 6. What Breaks First at Scale?
- **At 10x**: Direct playback of uncompressed 4K creator MP4 uploads freezes mobile browsers on slow cellular data.
- **At 100x**: Single WebSocket server instance memory exhaustion when 15,000 viewers join a celebrity chef's holiday live stream.
- **At 1,000x**: Egress bandwidth saturation without global CDN edge caching.

## 7. Senior Engineer Improvements
1. **Adaptive Bitrate Transcoding**: Use an automated FFmpeg worker to encode uploaded reels into an HLS `.m3u8` playlist with 480p, 720p, and 1080p stream tiers.
2. **Video Pre-Loading**: In `ReelsFeed.tsx`, preload the `.m3u8` playlist header of the next two reels in the feed, enabling instantaneous zero-buffer swipe transitions.
